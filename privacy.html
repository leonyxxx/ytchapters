Privacy policy

Last updated: 2026

ytchapters ("the tool") is a self-hosted automation operated by the owner of a single YouTube channel. This policy describes what the tool does with data.

1. What the tool accesses

  • Public video information of the one channel it is configured to watch (video id, title, publication time, live status).
  • Caption tracks that YouTube publishes for those videos, to build a chapter list.
  • Authorization to post a comment on that channel's own videos, granted by the channel owner through Google OAuth 2.0.

2. What is stored

The tool stores the OAuth refresh token issued by Google (so it can keep working unattended) and a local state file recording which videos were already processed, so the same comment is never posted twice. Both live on the operator's own server.

3. What is not done

  • No personal data of viewers, subscribers, or commenters is collected or stored.
  • No data is sold, shared, or transferred to third parties.
  • No YouTube account data is used for advertising, profiling, or training models.
  • No data is collected from any user other than the authorising channel owner.

4. Google user data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access is limited to posting a comment on the authorising account's own videos. The OAuth token can be revoked at any time at myaccount.google.com/permissions, which immediately stops all access.

5. Retention and deletion

The stored token and state file can be deleted at any time by removing token.json and state.json on the operator's server, or by revoking access in the Google account permissions page above. Captions are processed in memory and are not retained beyond the generated chapter list.
